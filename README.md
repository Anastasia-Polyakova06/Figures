# Figures

Проект создан на основе [ipetrushin/Figures](https://github.com/ipetrushin/Figures).

## Реализованная функциональность

Классы Rect, Circle и Square дополнены:
- наследованием от Figure
- реализацией интерфейса Transforming

### Поддерживаемые операции:
- **Перемещение** (move) — изменение координат фигуры
- **Поворот** (rotate) — поворот на 90° по часовой / против часовой относительно заданной точки
- **Масштабирование** (resize) — изменение размеров фигуры
